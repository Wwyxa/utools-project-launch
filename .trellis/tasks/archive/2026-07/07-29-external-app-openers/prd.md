# 支持配置外部应用打开项目

## Goal

让用户能够从项目的现有“在编辑器中打开”入口选择已配置的外部应用来打开项目，同时保留原有编辑器打开能力，减少在不同开发工具之间切换时的手工操作。

## Background

- 当前编辑器设置为当前设备上的单值偏好，内置 VS Code、Cursor 和一条自定义命令三种模式。
- 当前自定义编辑器命令支持 `{path}` 和 `{projectPath}` 项目路径占位符。
- 现有编辑器打开入口分布在项目卡片、项目详情和 Git 仓库操作中，最终均调用同一启动桥接能力。

## Requirements

- **R1 — 设备本地配置：** 当前设备维护一份供所有项目复用的外部应用列表；该列表不提供项目级覆盖，也不进入项目配置导入导出。
- **R2 — 通用应用模型：** 自定义应用包含名称、启动命令模板和启用状态，命令继续支持 `{path}` / `{projectPath}`；配置界面简要说明 `{path}` 表示本次打开目标的完整目录路径，`{projectPath}` 是含义相同的兼容别名；不按应用类别建立专用配置类型。
- **R3 — 预置应用：** VS Code 和 Cursor 作为不可删除的预置项保留，在不是默认项时可以停用，并可随时从设置页重新启用。
- **R4 — 配置管理：** 设置页采用类似环境显示项的紧凑行卡片，支持新增、修改、删除、启用和停用自定义应用，并允许从已启用应用中显式指定一个默认应用；新增和编辑在独立弹窗中完成，不使用常驻左右编辑区。
- **R5 — 默认项约束：** 默认应用必须保持启用，停用或删除默认项时阻止操作并提示先选择其他默认项。
- **R6 — 左键快捷打开：** 项目卡片、项目详情和 Git 相关直接入口保留现有图标；左键单击时使用默认应用打开对应项目或仓库路径。
- **R7 — 右键临时选择：** 右键单击直接入口时阻止浏览器默认上下文菜单，在入口附近显示所有已启用应用；选择仅影响本次打开，不修改默认值。
- **R8 — 键盘可访问性：** 应用选择菜单提供右键操作的键盘等价入口，并支持键盘导航、选择和关闭。
- **R9 — Git 菜单一致性：** Git 仓库已有的“更多操作”菜单直接展示可用应用选择，不要求用户在菜单项上再次右键。
- **R10 — 旧配置迁移：** 升级后将当前设备已保存的 VS Code、Cursor 或有效自定义编辑器偏好迁移为新的默认应用，无需用户重新配置。
- **R11 — 启动兼容：** 选择 VS Code、Cursor 或迁移后的自定义编辑器时，路径传递和启动行为与当前版本一致。

## Acceptance Criteria

- [ ] **AC1（R1、R4）：** 新增、编辑、启停或删除自定义应用后，重启插件仍保留变更；当前设备的其他项目立即使用同一列表，项目导出数据不包含该列表。
- [ ] **AC2（R3、R5）：** VS Code/Cursor 无删除操作，可在非默认状态下停用和重新启用；默认项的停用或删除尝试被拒绝且配置保持有效。
- [ ] **AC3（R4、R5）：** 只能将已启用应用设为默认，任何合法配置状态都恰好有一个可用默认应用。
- [ ] **AC4（R6、R11）：** 在项目卡片、项目详情和 Git 直接入口左键单击后，设置页指定的默认应用以正确目标路径启动。
- [ ] **AC5（R7）：** 直接入口右键菜单仅列出已启用应用；选择任一项可打开正确路径，完成后默认应用不变。
- [ ] **AC6（R8）：** 不使用鼠标也能打开菜单、遍历选项、启动应用并通过 Escape 关闭菜单，焦点返回合理位置。
- [ ] **AC7（R9）：** Git 仓库“更多操作”菜单可直接选择每个已启用应用，并清晰标识默认项。
- [ ] **AC8（R10、R11）：** 分别从旧版 VS Code、Cursor 和有效自定义命令配置升级时，原选项成为新默认应用且能继续打开项目。
- [ ] **AC9（R2、R11）：** 配置弹窗以当前界面语言简要解释两个路径占位符的含义；带空格的可执行路径和附加参数可通过命令模板配置，两个占位符都替换为本次打开目标的完整目录路径；无效命令返回失败而不破坏界面状态。
- [ ] **AC10（R6、R7、R9）：** 菜单在紧凑项目卡片、项目详情和 Git 面板中不被父级裁剪，窄窗口下保持在可视区域内。
- [ ] **AC11（R4）：** 外部应用在常规宽度下以紧凑多列卡片展示、窄窗口下自然收为单列；名称、默认状态、命令摘要和启用状态可直接扫描，新增/编辑弹窗不会造成设置页横向溢出。

## Out Of Scope

- 移除或替换现有编辑器打开能力。
- 按应用类别建立专用配置表单、参数模型或启动分支。
- 自动扫描注册表、应用安装目录或系统关联来发现外部应用。
- 自动提取可执行文件图标或新增第三方图标资源。
